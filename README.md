# Комната 1604

Хоррор-бродилка от первого лица в духе «1408». Вы заселились в 1604-й: обычный
номер на шестнадцатом этаже, минибар, гладильная доска, картина с ночным
отелем над диваном. Дверь закрывается за спиной сама, часы в гостиной
показывают 16:04, и до утра ещё далеко.

Девять уровней — девять минут на этих часах: `16:04 → 16:05`, `16:05 → 16:06`
и так далее до `16:13`. Часы и есть индикатор прогресса. Чем номер становится
с каждой минутой, игра не объясняет ни разу — но названия у минут взяты не из
гостиничного справочника.

Умереть и проиграть нельзя ни в одном круге. Ошибка не наказывается и ничего
не отнимает — она только не продвигает.

Godot 4.7, рендер `gl_compatibility`. Целевая площадка — Яндекс Игры.

## Играть

**[Открыть в браузере](https://kataevaa82-cmyk.github.io/room-1604/)**

Работает и на телефоне: управление переключается на сенсорное само.

## Управление

| Ввод | Действие |
|---|---|
| `WASD`, `Shift` | идти / быстрее |
| мышь | смотреть |
| `ЛКМ` | рассмотреть предмет (крутится мышью, на обороте бывают надписи) |
| `ПКМ` | положить обратно |
| `E` | тронуть |
| `1`–`4` | слот инвентаря |
| `H` | подсказка |
| `M` | карта этажа |
| `Esc` | пауза |

На телефоне: левая половина экрана — джойстик, правая — поворот взгляда,
кнопки действий справа внизу.

## Круги

| | Круг | Часы | Что делает игрок |
|---|---|---|---|
| I | Лимб | 16:04 → 16:05 | будит комнату вниманием, потом возвращает по памяти |
| II | Ураган | 16:05 → 16:06 | унимает ветер, читает чужие письма, отдаёт их обратно |
| III | Ненасытность | 16:06 → 16:07 | выносит еду, которой больше, чем помещается в руки |
| IV | Скупость | 16:07 → 16:08 | сводит спрятанные деньги с долгами по суммам |
| V | Гнев | 16:08 → 16:09 | всматривается в следы вспышки, потом унимает их |
| VI | Ересь | 16:09 → 16:10 | вскрывает запертое строго по порядку |
| VII | Насилие | 16:10 → 16:11 | разжимает то, что удержали в последний момент |
| VIII | Обман | 16:11 → 16:12 | разоблачает подделки по цепочке |

Замысел каждого круга описан отдельно: `КРУГ_II.md` … `КРУГ_IX.md`.

## Что не работает на GitHub Pages

Игра здесь запускается целиком, но **всё, что относится к Яндекс Играм,
работать не будет** — и это ожидаемо:

- реклама на переходах между кругами;
- облачные сохранения;
- `LoadingAPI` / `GameplayAPI`.

Причина: SDK подключается по относительному пути `/sdk.js`, который существует
только на хостинге Яндекса. Игра это переживает — слой площадки ждёт ответа
восемь секунд и дальше работает без неё, ничего не блокируя.

**Прогресс при этом сохраняется** — локально, в браузере. Уровень, на котором
вы остановились, запомнится, и обновление страницы его не потеряет.

## Сборка

```bash
# Обязательно после добавления любого скрипта с class_name,
# иначе ссылающийся на него файл просто не разберётся.
godot_console.exe --headless --path . --import

# Настольная сборка со всеми проверками
powershell -File tools/verify_release.ps1

# Веб-сборка для Яндекса: экспорт, быстрый лоадер, проверки и готовый ZIP
powershell -File tools/export_web.ps1
```

`tools/export_web.ps1` существует потому, что `html/head_include` в
`export_presets.cfg` **не применяется при экспорте из командной строки** —
это баг Godot, опция работает только из редактора. Скрипт вставляет тег SDK
и правила страницы после экспорта и проверяет результат поиском по
собранному `index.html`, а заодно вес (предел Яндекса — 100 МБ) и имена
файлов (без пробелов и кириллицы). Готовый к загрузке в Консоль архив создаётся
в `build/room1604-yandex.zip`; `index.html` лежит прямо в его корне.

До запуска WebAssembly браузер сразу показывает фирменный экран «Комнаты 1604»
с настоящим процентом загруженных байтов. `.wasm` и `.pck` начинают скачиваться
из `<head>`, стандартная заставка Godot не поставляется, а лоадер исчезает только
после первого отрисованного кадра меню. В этот же момент однократно отправляется
`LoadingAPI.ready()`.

## Проверки

Каждый круг проверяет сам себя без участия человека: число зон, отсутствие
пересечений между ними, достижимость каждой зоны настоящим лучом камеры,
проходимость всей цепочки до конца и корректность сброса.

С 15.08.2026 к этому добавлена `check_props_placed()` — предметы круга обязаны
стоять по месту. Проверка появилась после живой жалобы и сразу нашла четырнадцать
нарушений в семи кругах из девяти: счета висели в метре над полом, коробка была
утоплена в матрас по середину, лампа провалилась сквозь пол, платье висело выше
потолка. Условия два, и оба обязательны: габариты предмета подходят к какой-нибудь
геометрии номера ближе чем на 12 см (так проходят и лежащие на мебели, и висящие
на стене), и центр предмета не находится внутри коллизии (одного касания мало —
утопленная в кровать коробка касается кровати идеально).

```bash
LIMBO_AUDIT=1                              круг I
LUST_AUDIT=1   LIMBO_CIRCLE=2              круг II
GLUT_AUDIT=1   LIMBO_CIRCLE=3              круг III
GREED_AUDIT=1  LIMBO_CIRCLE=4              круг IV
WRATH_AUDIT=1  LIMBO_CIRCLE=5              круг V
HERESY_AUDIT=1 LIMBO_CIRCLE=6              круг VI
VIOL_AUDIT=1   LIMBO_CIRCLE=7              круг VII
FRAUD_AUDIT=1  LIMBO_CIRCLE=8              круг VIII
TREACH_AUDIT=1 LIMBO_CIRCLE=9              круг IX
FLOW_AUDIT=1                               прогресс и сохранения
SHELL_SHOT=res://qa_screens/shell          кадры всех экранов меню
```

Проверки намеренно не используют `assert`: он вырезается в release-сборке, и
сломанная цепочка молча печатала бы «OK». Вместо него провал гасит процесс с
ненулевым кодом.
