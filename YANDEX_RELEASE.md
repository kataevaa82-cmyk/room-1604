## Что изменено для платформы

- `tools/export_web.ps1` собирает Godot Web, добавляет `/sdk.js`, загрузочный
  экран, события `game_api_pause/game_api_resume`, обработку потери фокуса и
  создаёт `build/ROOM_1604_Yandex.zip`.
- `scripts/systems/Platform.gd` содержит мост Yandex Games SDK: Loading API,
  Gameplay API, рекламу, облачные сохранения и прямой JS→Godot callback для
  паузы дерева сцены и отключения главной аудиошины.
- `LoadingAPI.ready()` вызывается ровно один раз только после двух событий:
  SDK инициализирован и Godot отрисовал доступное игроку меню.
- Причины паузы учитываются раздельно (`focus`, `visibility`, `game_api`,
  `ad`), поэтому закрытие одного события не снимает другое.

## Пункт 2.14: автоопределение языка и английская версия

Предыдущая сборка была отклонена модерацией: «не реализовано автоматическое
определение языка через SDK». Замечание закрыто, и закрыто по существу — в игре
появился второй язык, а выбирает между ними площадка, а не игрок.

- язык берётся из `ysdk.environment.i18n.lang`; до ответа SDK — из
  `navigator.language`, и когда площадка отвечает, уже показанное меню
  пересобирается само;
- всё, что не русское, уходит в английский;
- **переведены все 1277 строк игры**: девять кругов, меню, пауза, карта этажа,
  экраны перехода и финала, сейф, режим осмотра, сенсорные кнопки, а также
  загрузочный экран, заголовок вкладки и атрибут `lang` документа;
- в меню есть кнопка языка — требование она не закрывает (его закрывает
  автоопределение), но позволяет модератору с русским аккаунтом посмотреть
  английскую версию.

## Результат браузерной проверки

Проверка выполнена в настоящем Chromium с загрузкой `index.wasm` и
`index.pck`, локальной имитацией официального `/sdk.js` и живым Godot canvas.

Успешно подтверждены:

- загрузка и отображение интерактивного главного меню;
- один вызов `YaGames.init()`;
- один вызов `features.LoadingAPI.ready()` после готового кадра;
- пауза Godot и mute при `blur`;
- восстановление host-состояния и звука при `focus`;
- пауза/mute и восстановление по `game_api_pause/game_api_resume`;
- пауза/mute на `callbacks.onOpen` полноэкранной рекламы и восстановление на
  `callbacks.onClose`;
- отсутствие прикладных JavaScript-исключений. Единственное игнорируемое
  исключение — запрет pointer lock в headless-документе без жеста пользователя;
- **автоопределение языка (пункт 2.14)**: тот же самый билд перезагружается с
  английской локалью площадки, и меняется при этом только ответ SDK — ни адрес,
  ни настройки браузера. Проверяются три наблюдаемых следствия: заголовок
  вкладки становится `ROOM 1604`, атрибут `lang` документа — `en`, и сама игра
  сообщает о себе `window.R1604.gameLang === 'en'`. Русская локаль в том же
  прогоне даёт `КОМНАТА 1604` / `ru` / `ru`.

Файлы доказательств:

build/yandex_browser_check_menu.png

Автоматический headless-ввод внутрь WebGL canvas не использовался как критерий:

готовность меню и фактические состояния паузы/аудио проверены напрямую.

## Как повторить

Из корня проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\export_web.ps1 `
  -OutputDir build/yandex_web_release `
  -ArchivePath build/ROOM_1604_Yandex.zip
```

Браузерный аудит:

```powershell
python tools\verify_yandex_web.py `
  --edge "C:\Program Files (x86)\Google\Chrome\Application\chrome.exe" `
  --web-dir build/yandex_web_release `
  --report build/yandex_browser_report.json `
  --screenshot build/yandex_browser_check.png `
  --timeout 120
```

Исходные файлы проекта не удалялись. Скрипт экспорта очищает и пересоздаёт
только генерируемый импортный кэш Godot и каталог выбранного Web-вывода.
Промоматериалы и отдельная памятка по ним находятся в `yandex_games_media/` и
`YANDEX_GAMES_MEDIA_HANDOFF.md`.
