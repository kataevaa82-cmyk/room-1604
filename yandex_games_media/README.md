# Yandex Games media kit — «Комната 1604»

Готовый набор визуальных материалов для карточки игры. Финалы находятся в
`art/final`, `screenshots/desktop/final` и
`screenshots/mobile_landscape/final`; реальные кадры из текущей сборки сохранены
рядом в папках `raw`.

## Что требует Яндекс

Требования сверены 15 августа 2026 года по официальному руководству:

- обязательная иконка: 512×512 px, PNG;
- maskable-иконка: важные элементы должны целиком находиться в центральной
  круглой безопасной зоне;
- обязательная обложка каталога: 800×470 px, PNG;
- опциональная обложка на витрину: 1560×520 px, PNG или JPG;
- обязательные скриншоты: 16:9 для альбомной ориентации или 9:16 для портретной,
  от 1280 до 2560 px по длинной стороне, JPEG или 24-битный PNG;
- минимум два скриншота для каждой выбранной платформы;
- реальный геймплей должен занимать не менее 70% изображения;
- если название присутствует на промоматериале, оно должно совпадать с
  названием в игре. В наборе везде используется точное название
  «КОМНАТА 1604».

## Готовые скриншоты

В `screenshots/desktop/final` лежат шесть десктопных PNG 1920×1080. В
`screenshots/mobile_landscape/final` лежат два мобильных альбомных PNG
1920×1080 с реальным сенсорным интерфейсом.

Тонкая тёмно-латунная рамка занимает менее 5% площади, поэтому реальный игровой
кадр остаётся примерно на 95% изображения. Геометрия, интерфейс, игровые тексты
и состояние сцен не дорисовывались.

## Пересборка

```powershell
python yandex_games_media/build_media.py
```

Скрипт заново делает точные размеры, общий цветовой финиш, рамки, превью и
проверяет режим, формат и разрешение каждого финального файла.
